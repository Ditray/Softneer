# Softneer 0.2

Автономная инженерная среда для Windows 10/11 x64. Включает 23 расчётных модуля, инженерный справочник и библиотеку STEP.

## Запуск портативной версии

1. Распакуйте **весь** архив `Softneer-0.2-Windows-x64.zip` в папку с правом записи.
2. В папке `Softneer` запустите `Softneer.exe`. Среда выполнения Electron поставляется в архиве. Расчёты, справочник и внутренний каталог работают офлайн.
3. Чтобы перенести настройки и добавленные STEP-файлы, закройте Softneer и скопируйте всю папку вместе с `SoftneerData`. Её приложение создаёт рядом с EXE.
4. В меню **Проект → Сохранить расчёты** можно выгрузить исходные параметры в отдельный файл `.softneer.json`. Команда **Открыть расчёты** загружает входные данные из файла с заменой сохранённых параметров соответствующих разделов. Добавленные STEP хранятся в отдельно переносимой папке `SoftneerData`.

Ввод принимает десятичную запятую и точку. При нажатии **Скачать отчёт** сохраняются исходные параметры, единицы, численные результаты и формулы. Отчёт расчёта и файл проекта имеют разные форматы. Внешние источники открываются в системном браузере.

## Механика и системы передач

| Раздел | Что рассчитывается |
| --- | --- |
| Система редуктора | До 12 последовательных прямозубых ступеней. Обороты и направление, момент, мощность, силы в каждой ступени. КПД и установившаяся температура при заданной теплопередаче. Выбранную ступень можно передать в расчёт зубьев или вала колеса. |
| Прямозубая пара | Геометрия несмещённой пары, силы, перекрытие и экспорт эвольвентных контуров в DXF. Переход к впадине упрощён. |
| Косозубая пара | Нормальное и торцовое сечения, смещения, рабочие диаметры и углы, осевое и торцовое перекрытие, окружная, радиальная и осевая силы. Передача геометрии и нормальной ширины в расчёт прочности. |
| Прочность зубьев | Контактное и изгибное напряжения, коэффициенты запаса по каждому колесу. Схема ISO 6336-2/-3 применяет коэффициенты и предельные напряжения, введённые расчётчиком. Пример формы иллюстративный. |
| Вал и опоры | Реакции двух опор, эпюра момента, оценка прогиба, эквивалентное напряжение и базовый ресурс подшипников. Вал сплошной и постоянного сечения. Силы задаются в двух плоскостях, включая нагрузки на консолях. |
| Допуски | H6–H8 с g6, h6, h7, js6 и k6 при номинале 1–500 мм, ручные предельные отклонения и линейные размерные цепи. |
| Ресурс, шлицы и движение | Подшипники L₁₀, правило Майнера, среднее давление в шлицевом соединении, анимация и кинематика кривошипно-ползунного механизма. |

При передаче из редуктора положение колеса сначала ставится посередине пролёта. Уточните координату и проекции сил по компоновке. Система моделирует последовательную передачу. Планетарные и разветвлённые системы, нелинейные опоры, контактный анализ, усталость вала и автоматический выбор нормативных коэффициентов остаются за рамками 0.2.

## Гидравлика по тематике Никитина и Яроца

За основу тематического охвата взято издание О. Ф. Никитина и В. В. Яроца «Основы гидравлики и гидропневмопривода», 2019, ISBN 978-5-7038-4953-8. [Библиографическая карточка МГТУ им. Н. Э. Баумана](https://library.bmstu.ru/Catalog/Details/548589)

| Задача | Расчётная модель |
| --- | --- |
| Сила на плоскую стенку | Давление, равнодействующая и центр давления для полностью смоченного прямоугольника. |
| Истечение из резервуара | Расход по Торричелли с заданным коэффициентом, время изменения уровня и объём. |
| Расходомер Вентури | Расход по Бернулли, пьезометрическому перепаду и заданному коэффициенту расхода, скорости и Re. |
| Утечка через щель | Ламинарная утечка, Re, вязкость и тепловые потери между неподвижными параллельными стенками. |
| Реакция потока на отвод | Сила на корпус по балансу импульса и двум давлениям. |
| Сеть трубопроводов | Дарси — Вейсбах, Кольбрук, ламинарный и переходный режимы. Последовательные группы с параллельными ветвями. Можно задать расход или доступный напор. |
| Рабочая точка центробежного насоса | Паспортные точки Q–H, КПД и NPSH, пересечение с характеристикой сети или кривой Hст + kQ². Сеть можно передать из расчёта трубопроводов. |
| Гидроудар | Скорость волны, фаза, быстрый и медленный затвор на одной линии. |
| Объёмный привод | Стационарная пара насос–гидромотор с раздельными объёмным и механическим КПД, баланс мощности и тепловые потери. |
| Гидроцилиндр | Усилие, скорость, площади и мощность для хода в обе стороны. |
| Гидротурбина и гидротрансформатор | Мощность и момент турбины по Q и H. Характеристика трансформации, КПД и потери по заданной кривой K(i). |

Формулы, границы применения и исходные данные примеров приведены в приложении. Покрытие главы за главой по всем задачам учебника не сверялось. Общие кольцевые сети, полная динамика гидропривода, проектирование гидромашин и пневмоприводы в 0.2 не реализованы.

## Справочник и CAD

В справочнике 12 статей с поиском. В каталоге 42 типоразмера шайб, шпонок, штифтов и подшипников. Встроенные STEP представляют номинальные габариты в миллиметрах с фасетными цилиндрическими поверхностями. Импорт собственных файлов принимает STEP Part 21 в расширениях `.step` и `.stp`. Совместимость STEP с конкретной системой проверяется импортом в этой системе.

## Исходники и проверка

`index.html` можно открыть напрямую для проверки интерфейса. Источники `src/engine.js`, `src/drivetrain.js` и `src/hydro.js` содержат расчётное ядро. Приложение для Windows использует `desktop/main.cjs`. Для численных проверок нужен Node.js 20+.

```sh
node --test tests/*.test.js
```

Сценарий упаковки требует оригинальный Windows x64 ZIP Electron 44.11.3 и файл контрольных сумм того же выпуска. Первый запуск сборки выполняется из распакованного каталога.

```sh
sh scripts/package-windows.sh /path/electron-v44.11.3-win32-x64.zip /path/SHASUMS256.txt /absolute/path/Softneer-0.2-Windows-x64.zip
```

[Официальный выпуск Electron 44.11.3](https://github.com/electron/electron/releases/tag/v44.11.3)
