# Softneer 0.1

Локальная инженерная среда с расчётами, справочником и каталогом моделей STEP.

## Запуск

1. Скачайте архив исходников и распакуйте его целиком.
2. Откройте `index.html` в Safari, Chrome, Edge или Firefox. Для расчётов и встроенного каталога интернет не нужен.
3. Выберите раздел слева. Ввод принимает десятичную запятую и точку. Исходные данные запоминаются, если браузер разрешает локальное хранение.

Ссылки на внешние источники открываются отдельно. Поиск доступен через верхнюю панель или клавиши Ctrl+K / ⌘K.

## Расчёты

| Раздел | Результат | Область применения |
| --- | --- | --- |
| Зубчатые передачи | Диаметры, межосевое расстояние, перекрытие, силы, скорости, DXF | Внешняя прямозубая пара без смещения профиля. Расчёт прочности ISO 6336 требует отдельной проверки. |
| Допуски и посадки | Предельные размеры, зазор, натяг | H6–H8 с g6, h6, h7, js6 и k6 при 1–500 мм. Для других полей доступен ручной ввод. |
| Размерные цепи | Номинал, предельные размеры и допуск замыкающего звена | Метод максимума и минимума для линейной цепи со знаками. |
| Подшипники | Базовый L₁₀ в оборотах и часах, требуемая грузоподъёмность | Постоянная эквивалентная динамическая нагрузка и частота. Надёжность 90% по базовой модели ISO 281. |
| Шлицевые соединения | Среднее давление и запас по давлению | Предварительная оценка по заданной рабочей площади. Размеры и допуски DIN 5480 и ISO 4156 задаёт пользователь. |
| Усталостный ресурс | Повреждение и оценка ресурса повторяющегося блока | Линейное суммирование по Майнеру. Числа циклов до отказа вводятся по выбранной кривой S–N. |
| Моделирование движения | Анимация, положение, скорость, ускорение и ход | Кинематика соосного кривошипно-ползунного механизма при постоянных оборотах. |
| Гидроцилиндр | Усилие, скорость, рабочая площадь и гидравлическая мощность | Один активный объём при заданных давлении, расходе и механическом КПД. |

Кнопка **Скачать отчёт** выгружает исходные величины, единицы, методику, результаты и сообщения расчёта в JSON. Во вкладках **Пара**, **Шестерня** и **Колесо** команда **Экспорт DXF** использует видимый набор контуров. В DXF хранятся замкнутые полилинии в миллиметрах. Переход к впадине упрощён. Для изготовления проверьте форму впадины, смещение, подрезание и требуемые припуски.

## Справочник и модели

В справочнике 12 статей с поиском и фильтрами. Темы охватывают МКЭ, ТММ, машиностроение, ГОСТ/ЕСКД, ISO и DIN, электротехнику, электронику, гидравлику, физику и химию. Карточки стандартов ведут на официальные источники.

В каталоге 42 компоновочных типоразмера шайб, шпонок, штифтов и подшипников. Встроенные файлы генерируются как замкнутые гранёные BREP-модели STEP в миллиметрах. Круглые поверхности представлены 96 сегментами. Фаски, допуски и внутреннее устройство подшипников в этих моделях отсутствуют.

Команда **Добавить STEP** принимает текстовые файлы `.step` и `.stp` в формате ISO 10303-21. Программа проверяет заголовок и завершение файла и сохраняет оригинал в хранилище браузера. Приложение показывает сообщение, когда хранилище недоступно и файл остаётся только до закрытия вкладки. Для долгосрочной работы с библиотекой с одного и того же адреса можно раздавать директорию локальным HTTP-сервером, например командой `python3 -m http.server 8000 --bind 127.0.0.1`, и открывать [локальную страницу](http://127.0.0.1:8000).

## Проверка и структура

Запуск автоматических проверок на Node.js 20+ из каталога проекта

```sh
node --test tests/*.test.js
```

Проверяются численные примеры, границы интервалов, производные кинематической модели, единицы и замкнутость DXF-контуров, габариты, ориентация оболочек и ссылки между сущностями всех STEP-моделей. Совместимость с конкретной CAD-системой проверяется импортом в ней.

- `src/engine.js` — формулы и экспорт DXF.
- `src/cad.js` — каталог, геометрия деталей и экспорт STEP.
- `src/content.js` — формы, пояснения и статьи.
- `src/draw.js` — схемы на Canvas.
- `src/app.js` — навигация, поиск, интерфейс и локальное хранение.
